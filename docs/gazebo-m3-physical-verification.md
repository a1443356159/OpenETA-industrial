# M3 状态：已关闭，等待 DetachableJoint 设计确认

当前仓库没有可执行的 M3 抓取或放置能力。任何创建 M3 profile 的请求都会以
`DETACHABLE_JOINT_UNIMPLEMENTED_OR_UNAPPROVED` 失败；M4 操控链因此同样
fail-closed。不存在用于维持、跟随、补偿或推断抓取状态的替代机制。

M3 仅保留目标、干扰物和桌面尺寸等静态场景元数据，供 Oracle 感知和离线
manifest 契约使用。这些元数据不能证明抓取、搬运、放置或正式验收通过。

此前的 M3 报告和日志只保留为失效实现的诊断证据，不能作为 M3 或 M4 通过
的依据。新的原生 joint 拓扑、接触判据、ACK、释放/复位时序、测试和远端
验收方案必须先获得明确书面设计确认，之后才可以新增或恢复任何资产。
