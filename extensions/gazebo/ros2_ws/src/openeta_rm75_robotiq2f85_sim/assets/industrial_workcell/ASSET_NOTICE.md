# Offline industrial workcell assets

All runtime assets in this directory are vendored and hash-pinned. Gazebo does
not access the network while launching the workcell.

The five tool meshes are derived from the STARS Laboratory Workshop Tools
Dataset at commit `48928088e4877c872ea5aaed92f2ef315190153a` (MIT). Their
millimetre PLY geometry was deterministically converted to metre-scale,
tabletop-oriented OBJ and recoloured for the sorting task.

`picking_bin.glb` is Open Robotics' `Picking_Bin` version 1 from Gazebo Fuel,
used unchanged under CC BY 4.0.

The bolt meshes are generated by OpenETA's dependency-free asset builder.
Their metric pitch parameters were checked against tq-threads commit
`08d4700532dac58f8c983312a1965948e2533875` (MIT).

Exact sources, transformations, licenses, and hashes are in
`asset_manifest.json`.
